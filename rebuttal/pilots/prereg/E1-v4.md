# E1 pre-registration v4 — N = 80 planned, pending author confirmation (+31.5 h)

2026-11-08. No human labels exist. No sample or matcher is frozen. This version supersedes v3 prospectively; historical pilots retain their original hashes. Reapplying the fixed lexical-only SHA draw at N=80 yields the same 80 IDs as the earlier candidate design; no outcomes or matcher labels enter selection.

**Primary:** weighted fact-presence human–human Cohen κ and matcher accuracy, with 95% instance-cluster-bootstrap CIs. **Also reported:** weighted fidelity accuracy. Fidelity κ is secondary, alongside nominal Gwet AC1 using the same rows, instance weights and bootstrap. κ's interval is wide because almost every fact is faithful, so a wide κ is not evidence of poor agreement.

AC1 is fixed before labels: weighted observed agreement P_o; pooled mean of the two weighted human category marginals p_c; P_e=Σ p_c(1−p_c)/(q−1); AC1=(P_o−P_e)/(1−P_e). Fixed categories are absent, faithful, partial, distorted (q=4); absent permits a human disagreement about an adjudicated-present fact. Uncertain rows are counted and excluded, never recoded. Formula source: Gwet's AgreeStat guide, §4.4, https://www.agreestat.com/documents/agreestatguide.pdf . Report AC1 beside κ, not as a replacement selected after seeing results.

Presence/fidelity definitions, trace lost/reached-but-unused secondary, partial-as-lost sensitivity, human MQ/SB candidate-aggregation-failure named outputs and all-trace denominator remain as specified in E1-v3-archived.md. No acceptance thresholds. Failed matcher labels stay errors. All 20 dev instances are certainty units for the full-frame rate only, not matcher validation.

Sampling frame: 85 MQ and 47 SB non-dev instances. Strata: benchmark × cached Qwen k=3 lexical CR at strict τ=0.5 (zero, incomplete, complete). No correctness or matcher output defines the draw. Allocate 60 MQ +20 SB; equal round-robin within nonempty strata, cap at stratum population. Order by SHA256 canonical JSON ["E1-lexical-v3",42,stratum,instance_id], ID tie-break. Inclusion π_h=n_h/N_h; inverse weight w_i=N_h/n_h. Every model/fact inherits its instance weight. Weighted κ, accuracy and AC1 use 2,000 within-stratum instance-cluster bootstrap draws, seed42, percentile95% CIs, no finite-population correction; report undefined κ draws.
