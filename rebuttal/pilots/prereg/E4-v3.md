## Analysis amendment A1 (matched pairs, balance table, all-case sensitivity), fixed 2026-11-08 before the new balance analysis

This amendment is prospective for final evaluation. Historical technical pilot outcomes already exist; they are not a confirmatory test of this amendment. For the present balance export read only action manifests, donor manifests and raw input text, never repair answers or success scores. Do not inspect outcomes by failure group.

The main matched-repair-versus-mismatched-repair comparison continues to use ALL cases, unchanged. The separate repair-minus-its-volume-control comparison includes only pairs with the same added-unit count and exact base-token counts within ±10% of repair length. Report matched/possible pair counts and unique-instance counts for every failure group × benchmark, including zero cells. Partial remains separate; correct controls are not failure groups.

Before outcome analysis, report matched versus unmatched balance at the pair level (three possible repair/control pairs per case): failure type; benchmark; protocol (SB-5, SB-10, MQ); base model; raw trace token length; repair added-unit tokens; control added-unit tokens. Raw trace length is the exact base tokenizer count of question plus extraction pool plus board texts joined with newlines; exclude generated repair/control answers. Numeric summaries: count and median, plus SMD=(mean_M−mean_U)/sqrt((var_M+var_U)/2), sample variances. Categorical summaries: count/proportion for each level, SMD=(p_M−p_U)/sqrt((p_M(1−p_M)+p_U(1−p_U))/2). Equal constants yield SMD=0; nonzero differences with zero variance yield undefined, reported NA. No outcome-based trimming or donor reselection.

All-case sensitivity: for each repair/control pair define D=Y_repair−Y_control, where Y is the preregistered benchmark score. Fit ordinary least squares
D ~ 1 + C(failure_type) + C(protocol) + C(base_model) + C(repair_arm) + log(1+T_repair) + log(1+T_control).
Use every matched and unmatched pair. Estimate the standardized equal-volume contrast by predicting for all observed rows with T_control set to T_repair and averaging within the reported group/benchmark. This is a model-adjusted sensitivity, not randomized identification of volume effects. Fit independently by benchmark if scoring scales differ. Cluster bootstrap by instance jointly preserving all models/arms, 2,000 draws, seed 42, percentile 95% CI, refitting each draw. Drop absent factor levels per fit. If the observed fit or a draw is rank deficient or has no residual degrees of freedom, mark it non-estimable; report the number of valid draws, and do not publish a CI if fewer than 95% of draws are valid. N<10 instances remains descriptive. Do not fit this model to five technical pilot items.

Always show the unadjusted matched-pair contrast and adjusted all-case sensitivity together. A differing effect direction or differing 95% CI exclusion of zero must be stated in plain words; do not silently select the favorable result. Matched cases may be unrepresentative, which the balance table quantifies. Final donor/label/action manifest and author swap checks remain required before intervention outcomes; constructed controls are NOT authorized by this amendment.
