## Analysis amendment A1 (matched pairs, balance table, all-case sensitivity), fixed 2026-11-08 before the new balance analysis

This amendment is prospective for final evaluation. Historical technical pilot outcomes already exist; they are not a confirmatory test of this amendment. For the present balance export read only action manifests, donor manifests and raw input text, never repair answers or success scores. Do not inspect outcomes by failure group.

The main matched-repair-versus-mismatched-repair comparison continues to use ALL cases, unchanged. The separate repair-minus-its-volume-control comparison includes only pairs with the same added-unit count and exact base-token counts within ±10% of repair length. Report matched/possible pair counts and unique-instance counts for every failure group × benchmark, including zero cells. Partial remains separate; correct controls are not failure groups.

Before outcome analysis, report matched versus unmatched balance at the pair level (three possible repair/control pairs per case): failure type; benchmark; protocol (SB-5, SB-10, MQ); base model; raw trace token length; repair added-unit tokens; control added-unit tokens. Raw trace length is the exact base tokenizer count of question plus extraction pool plus board texts joined with newlines; exclude generated repair/control answers. Numeric summaries: count and median, plus SMD=(mean_M−mean_U)/sqrt((var_M+var_U)/2), sample variances. Categorical summaries: count/proportion for each level, SMD=(p_M−p_U)/sqrt((p_M(1−p_M)+p_U(1−p_U))/2). Equal constants yield SMD=0; nonzero differences with zero variance yield undefined, reported NA. No outcome-based trimming or donor reselection.

All-case sensitivity: for each repair/control pair define D=Y_repair−Y_control, where Y is the preregistered benchmark score. Fit ordinary least squares
D ~ 1 + C(failure_type) + C(protocol) + C(base_model) + C(repair_arm) + log(1+T_repair) + log(1+T_control).
Use every matched and unmatched pair. Estimate the standardized equal-volume contrast by predicting for all observed rows with T_control set to T_repair and averaging within the reported group/benchmark. This is a model-adjusted sensitivity, not randomized identification of volume effects. Fit independently by benchmark if scoring scales differ. Cluster bootstrap by instance jointly preserving all models/arms, 2,000 draws, seed 42, percentile 95% CI, refitting each draw. Drop absent factor levels per fit. If the observed fit or a draw is rank deficient or has no residual degrees of freedom, mark it non-estimable; report the number of valid draws, and do not publish a CI if fewer than 95% of draws are valid. N<10 instances remains descriptive. Do not fit this model to five technical pilot items.

Always show the unadjusted matched-pair contrast and adjusted all-case sensitivity together. A differing effect direction or differing 95% CI exclusion of zero must be stated in plain words; do not silently select the favorable result. Matched cases may be unrepresentative, which the balance table quantifies. Final donor/label/action manifest and author swap checks remain required before intervention outcomes; constructed controls are NOT authorized by this amendment.


## Amendment A2 — constructed same-volume control, Silo-Bench only (approved option A, 2026-11-08; build after the lead acknowledges the card)

A2 is added in this new version file; v3 is unchanged apart from a "superseded" line. No outcome has been read and no code exists. MuSiQue is **not** covered: it stays pending its matched and unmatched pair counts, which are exported from the frozen case list before any outcome is read and sent to the lead before anything for MuSiQue is built.

**Trigger.** Once the case list is frozen and **before any outcome is read**, count natural matched repair/control pairs (A1 rule: equal unit counts, added tokens within ±10%) in every Silo-Bench cell, where a cell is a failure group × Silo-Bench setting (SB-5, SB-10). A cell with **fewer than 5 natural matched pairs** is triggered. In a triggered cell, every pair that has no natural match gets one constructed control. Matched pairs in that cell keep their natural control. Cells with 5 or more natural matched pairs get no constructed control.

**Selection rule (deterministic; no model writes any text).** The control text is taken from the donor agent's own source shard: the same donor as the natural control (the first other agent holding no support-set fact; if none, the flagged fallback of E4-v3). A segment is a whole sentence, or, for Silo-Bench shards that are data lists, a whole record or line; segments are never cut. Candidate segments are ordered by ascending SHA-256 of canonical JSON ["E4-construct-v1", 42, case_id, arm, segment_index], segment_index as tie-break. Segments are taken in that order until the unit count equals the repair's added unit count and the exact base-tokenizer token count is within ±10% of the repair's added tokens; a segment that would push the count outside ±10% is skipped and the next is tried. No segment from the target agent and no segment that carries a needed fact (any support-set carrier) is ever used.

**Checks.** (1) One Qwen-235B call checks that the selected text does not state or imply any needed fact and is faithful to its source. (2) Two authors independently check the final text, 5 minutes each: faithful to its source; not part of any sufficient set; does not restore, correct or re-derive the missing fact. **Any failure by Qwen or either author means redraw.**

**Redraw limit.** A failed selection is discarded and the rule is applied again to the remaining segments (the failed segments are never reused). At most 2 redraws per control (3 selections). If none passes, no control is built for that pair and it is reported as "no same-volume control available". Target evidence is never used as padding.

**Run.** The constructed control is a new arm: the selected segments are added to the donor agent's board contribution as board units and the base model makes one aggregation call. It is in addition to the natural V-arms, which still run on every case (they are needed for the all-case sensitivity of A1).

**Reporting.** Built and natural controls appear in **separate rows or columns in every table and are never pooled**, each with its pair count. The A1 matched-pair and all-case analyses use natural controls only; the constructed-control contrast is estimated separately with the same estimator and cluster bootstrap. Cells that remain sparse, including pairs whose control could not be built, are reported as **"no same-volume control available"**. Built-control results are never described as natural.

**Cost (planning).** Per pair 2 calls (Qwen check plus aggregation) plus 1 Qwen call per redraw. About 40–50 pairs expected (at most 90): about 80–100 calls (at most 360 with 2 redraws on every pair), about $0.05–0.06 (at most $0.23), 7–8 h of author time in total, about 2 h per author (each author-failed redraw adds 10 author-minutes).

**Execution lock.** No code and no calls until the lead acknowledges the card. After that: build, unit-test the selection rule (deterministic, unit count equal, tokens within ±10%, no target or support-set segment) and the reporting separation, and pilot on 2–3 reserved Silo-Bench pairs with an author check, before any use on the evaluation case list.
